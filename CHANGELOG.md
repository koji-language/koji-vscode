# Changelog

## 0.2.0

For Koji 0.2.0:

-   Format Document, and formatting when a file is saved, in the style of Koji (`kojic fmt`), with
    the language server of Koji 0.2.0 (with an earlier `kojic`, files are not formatted).
-   The hover shows the comment above a declaration as its documentation, from the language server
    of Koji 0.2.0.

## 0.1.1

-   The icon is the logo of Koji: a wooden box of rice.

## 0.1.0

The first version, for Koji 0.1.0:

-   Syntax highlighting for Koji (`.kj` files), with the TextMate grammar of Koji.
-   Comments with `Ctrl+/`, matching brackets and quotes, and indentation after `{`, `(` and `[`.
-   The language server of Koji (`kojic lsp`): the errors of a file as it is edited, the type of
    what is under the mouse, and where a name is declared.
